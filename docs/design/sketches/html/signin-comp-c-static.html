ryft

A schema version control system

Branch a Postgres schema, edit it in a structured editor, and merge it back into main.

  • A rename keeps the column.
  • A merge is a typed report.
  • main is the schema of record.

How it works

  1. 1Give a username
  2. 2Land in the seeded database
  3. 3Create a branch, edit, open a merge request

A name this workspace has seen resumes that user.
A new name creates one. There is no separate sign up.
No password.
