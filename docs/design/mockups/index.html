Every mockup shows the same screen: reviewing contact-fields → main, with the rename-rebase case (index follows the renamed column) and one real conflict (both sides retype users.phone).

  1. The Revised Drawingthe roll

    Schema as a controlled engineering drawing. Revision table, revision clouds around what diverged, a title block with a checker’s sign-off, drafting-vellum ground.

  2. The Accession Registerthe pick

    Every object gets a permanent accession number. Renamed cards keep the number; cross-reference slips point at numbers, not names. Ledger-cream, typewritten.

  3. The Three-Track Scorealternate

    Base runs down a centre spine; ours-changes align left, theirs-changes align right on the same object row. Shaped blocks encode change kind.

  4. The Darkroom Linealternate

    The merge as fixed ordered stations with a test-strip dry run you read before committing. Amber safelight on near-black; irreversible past the fixer.

  5. Signal at the Edgealternate

    The schema text stays calm and colourless. Every change and its severity live in a hairline gutter band and a margin note — nothing fills the row.
